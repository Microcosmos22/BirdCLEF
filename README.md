# BirdCLEF - Acoustic Species Identification in the Pantanal, South America

This project aims to predict birds and amphibious species from audio recordings provided by different biology research groups.
We code and train from scratch, leveraging state-of-the art AI techniques such as Model Stacking/Blending, usage of priors (bayesian probab.) as well as advanced data analysis pipelines.
